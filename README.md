# ژورنال معاملاتی

این بسته برای انتشار نسخه HTML ژورنال معاملاتی در GitHub Pages آماده شده است.

## محتویات
- `index.html` فایل اصلی برنامه
- `manifest.webmanifest` مشخصات نصب به‌صورت وب‌اپ
- `icon.svg` آیکون برنامه
- `sw.js` سرویس‌ورکر برای پوسته آفلاین برنامه

## بارگذاری در GitHub
1. فایل ZIP را استخراج کن.
2. وارد مخزن GitHub خودت شو.
3. از **Add file → Upload files** استفاده کن.
4. هر چهار فایل پروژه به‌همراه README را در ریشه مخزن بارگذاری و Commit کن.
5. در **Settings → Pages**، شاخه `main` و پوشه `/ (root)` را برای انتشار انتخاب کن.
6. پس از آماده شدن GitHub Pages، سایت را با آدرس مخزن باز کن.

## نکته مهم درباره ورود و همگام‌سازی
این نسخه مانند فایل اصلی به تنظیمات سرویس Supabase متکی است. قبل از انتشار عمومی، آدرس پروژه، کلید عمومی و تنظیمات احراز هویت Supabase را در فایل HTML بررسی کن. کلید `service_role` یا هر کلید محرمانه‌ای نباید در فایل سمت کاربر قرار بگیرد.

برای نصب PWA و سرویس‌ورکر، برنامه باید از طریق HTTPS (مانند GitHub Pages) اجرا شود؛ باز کردن مستقیم فایل با `file://` این قابلیت را فعال نمی‌کند.
