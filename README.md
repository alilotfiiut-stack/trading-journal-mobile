# ژورنال معاملاتی — نسخه ۱۶ (PWA)

این پوشه برای انتشار مستقیم در GitHub Pages آماده شده است.

## انتشار در GitHub
1. یک repository جدید بسازید.
2. تمام فایل‌های داخل این پوشه (`index.html`، `manifest.webmanifest`، `sw.js` و `icon.svg`) را در ریشه repository بارگذاری کنید.
3. در بخش **Settings → Pages**، گزینه **Deploy from a branch** را انتخاب کنید؛ شاخه `main` و پوشه `/ (root)` را مشخص و ذخیره کنید.
4. پس از انتشار، آدرس HTTPS سایت را روی گوشی باز کنید و از منوی مرورگر گزینه نصب/افزودن به صفحه اصلی را بزنید.

## نکته مهم درباره اطلاعات
اطلاعات محلی مرورگر با پاک‌کردن داده‌های سایت یا تعویض دستگاه ممکن است از بین برود. از بخش پشتیبان‌گیری برنامه مرتب نسخه پشتیبان تهیه کنید. برای قابلیت‌های آنلاین، اتصال اینترنت و تنظیمات سرویس ابری مورد استفاده برنامه لازم است.

## تغییر نسخه
برای به‌روزرسانی بعدی، فایل `index.html` و مقدار `CACHE_NAME` در `sw.js` را تغییر دهید تا کش نسخه قبلی جایگزین شود.
