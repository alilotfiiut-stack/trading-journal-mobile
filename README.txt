ژورنال معاملاتی - نسخه 13

محتویات:
- index.html: برنامه اصلی (برگرفته از آخرین نسخه HTML ذخیره‌شده)
- manifest.webmanifest: تنظیمات نصب به شکل وب‌اپ
- icon.svg: آیکون برنامه
- sw.js: سرویس‌ورکر برای کش پوسته برنامه

انتشار در GitHub Pages:
1) محتویات این پوشه را در ریشه یک repository قرار بده.
2) در GitHub وارد Settings > Pages شو.
3) در بخش Build and deployment گزینه Deploy from a branch را انتخاب کن.
4) شاخه main و پوشه /(root) را انتخاب و Save کن.
5) پس از انتشار، آدرس GitHub Pages را با HTTPS باز کن.

نکته: همگام‌سازی ابری و تصاویر به اتصال اینترنت و تنظیمات پروژه Supabase وابسته‌اند. کلید موجود در فایل از نوع publishable است؛ سیاست‌های دسترسی (RLS) و مجوزهای Storage باید در Supabase درست تنظیم شده باشند. فایل HTML به‌تنهایی جایگزین پیکربندی Supabase نیست.
